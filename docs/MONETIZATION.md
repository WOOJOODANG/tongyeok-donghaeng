# 통역 동행 — 유료화 설계 (실결제 전환 가이드)

## 현재(v4.0)
- 계정·요금제 화면, 무료 한도(브리핑/사진 하루 3회), Pro 전용 기능 잠금, **테스트 결제** 흐름 구현.
- 소유자(개발자) 모드: 본인은 전 기능 무제한 (기본 ON).
- 모든 판정은 폰(localStorage)에서 → **우회 가능하므로 실판매 전 서버 필수**.

## 요금제(안)
| 플랜 | 월 | 내용 |
|---|---|---|
| 무료 | 0 | 무료 엔진 통역, 오늘의 단어/문장, 브리핑·사진 3회/일 |
| Pro | 19,900 | 브리핑·사진 무제한, 고객관리, 코스 전체, 공유 패키지 |
| 기관 | 29,900/좌석 | Pro + 팀 공유, 기관 로고, 좌석 관리 |

AI 비용: 사용자가 **자기 API 키**를 넣는 방식(BYOK) → 원가 0. 추후 '키 없이 쓰는 플랜'은 서버 프록시 + 사용량 과금 필요.

## 실결제 전환 단계
1. 사업자등록(간이/일반), 통신판매업 신고
2. 결제대행 계약: 토스페이먼츠(정기결제/빌링키) 또는 포트원
3. 서버(예: Supabase/Firebase): 로그인(구글·카카오), users/subscriptions 테이블, 결제 웹훅으로 구독 갱신
4. 앱: extras.js의 plan()을 서버 조회 결과로 교체 (캐시 1일, 오프라인 유예 3일)
5. 약관·개인정보처리방침·환불정책 페이지
6. (선택) 구글 플레이 출시: TWA(Bubblewrap)로 PWA 포장 — 플레이 결제 정책 확인

## 개인정보
고객 정보·상담 기록은 기기 저장 유지(서버 미전송)가 기본. 팀 동기화는 암호화 + 별도 동의.
