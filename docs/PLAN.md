# 통역 동행 — 기획서 (확정 v1, 2026-11-21)

## 목표
마이크 없는 PC 대신 갤럭시 폴드8 와이드(안드로이드 크롬) PWA로, ▶ 한 번 누르면 종료 전까지
한국어 ↔ 상대 언어 연속 통역 + 상담 브리핑 문서 + 니즈/최적 제안.

## 언어
한국어 ↔ 영어 / 중국어 / 러시아어 / 일본어 / 스페인어 (lib 테이블로 확장 가능)

## 엔진 3단 (A안)
| 모드 | 인식 | 번역 | 음성 | 키 |
|---|---|---|---|---|
| ① 무료 | 크롬 Web Speech (턴 자동 교대) | Gemini 2.5 Flash | 폰 내장 TTS | Gemini |
| ② 절약 | gpt-4o-mini-transcribe (언어 자동감지, VAD 분할) | gpt-4o-mini | gpt-4o-mini-tts | OpenAI |
| ③ 프리미엄 | OpenAI Realtime (WebRTC 음성→음성) | ← | ← | OpenAI |

- OpenAI 키 없음 → ②③ 🔒 회색, 탭 시 가입·충전 안내 팝업
- 잔액부족(insufficient_quota) → "무료 모드로 전환?" 팝업
- 월 사용 한도(원) 초과 → 자동 무료 전환, 이번달 사용액 표시(추정)

## 전문 모드
물리치료(+수업) / 보험(금소법 설명의무) / 상속·증여·세무·기장 / 일반 — 용어 프롬프트

## 화면
- 상단: 언어·전문모드·엔진 선택, ▶/■
- 대화 자막 버블(원문+번역), 큰 글씨, 폴드 대면 모드(상단 절반 180° 회전, 상대 언어)
- 시작 시 상대 언어 동의 팝업

## 브리핑
3줄 요약 / 요청·고민 / 합의 / 다음 할 일 / 확인 필요 / 💡 숨은 니즈·최적 제안·추가 질문 / 고객용(상대 언어) 요약
→ 공유(카카오톡 등 안드로이드 공유시트), 이메일, 복사, PDF(인쇄), HTML 파일 저장. 기록은 기기(localStorage)만.

## 보안
키는 기기 localStorage만 저장, 코드/저장소에 키 없음. 음성 원본 저장 안 함. AI 제안은 참고용 문구.

## v2 영어 연습(🎓)
오늘의 단어 8개/문장 5개(하루 캐시, 전문모드 연동, 레벨), 한→영 3가지 스타일, 따라말하기 → Gemini 음성분석(정확도·발음·유창성·강세억양·WPM·단어교정·강세표기), 전화영어 AI 롤플레이(5개 상황, 턴별 교정, 종료 피드백), 연속일·점수 통계.
